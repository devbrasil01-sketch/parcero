# Parcero 🤝
> **Parcero conecta quem tem o cliente a quem tem o imóvel.**

Plataforma SaaS B2B brasileira de parcerias imobiliárias entre corretores autônomos e imobiliárias. Encontre parceiros confiáveis, registre a indicação com segurança jurídica e acompanhe cada oportunidade até o fechamento e comissão.

---

## 🎨 Identidade Visual & Design System
- **Deep Navy** (`#102A43`): Títulos, cabeçalhos, rodapé e solidez institucional.
- **Warm Sand** (`#F5F1E8`): Fundo de blocos contrastantes e elegância B2B.
- **Electric Teal** (`#16B8A6`): Botões de ação principais (CTAs) e badges de conversão.
- **Sky Blue** (`#46A6FF`): Detalhes, tags de encaixe e status de progresso.
- **Tipografia**: [Plus Jakarta Sans](https://fonts.google.com/specimen/Plus+Jakarta+Sans) (geométrica, moderna e limpa).

---

## 🚀 Como Executar Localmente

### Opção 1: Com Python 3 (recomendado)
```bash
python -m http.server 3000
```
Acesse em: `http://localhost:3000`

### Opção 2: Com Node.js / npx
```bash
npx serve .
```
